# zal.ai

Готовый одностраничный сайт-портфолио с формой заявки.

## Важно

В `index.html` уже подключён Google Apps Script URL:

`https://script.google.com/macros/s/AKfycbzctkYGUSEEdG_cejOCjCUhR8wMD1SbE4jeTSEktzLnBgtWU7dnQdX9BIiczw195yVpzw/exec`

Перед проверкой формы в Google Apps Script должна быть опубликована функция `doPost(e)`.

## Публикация на Vercel

Загрузите `index.html` в GitHub-репозиторий и задеплойте его через Vercel. Если проект уже подключён к Vercel, замените старый `index.html` и сделайте новый commit/push.
